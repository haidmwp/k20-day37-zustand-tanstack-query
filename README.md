# K20 Day 37 - Zustand & TanStack Query

Bài tập React kết hợp:

- Zustand quản lý giỏ hàng tạm thời.
- TanStack Query tải danh mục và sản phẩm từ DummyJSON.
- Chọn danh mục là client state (`useState`).
- Danh mục và sản phẩm là server state do TanStack Query quản lý/cache.
- Sản phẩm API có thể thêm trực tiếp vào giỏ hàng.

## Chạy project

```bash
npm install
npm run dev
```

## Build
